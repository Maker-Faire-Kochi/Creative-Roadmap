# Maker Faire Kochi 2027 — Creative Content Roadmap

A single-page interactive roadmap that maps the entire content strategy for **Maker Faire Kochi 2027** (Jan 23–24, 2027). Built as a zero-dependency, responsive, printable HTML document with **Maker Stories** as the core editorial engine.

## What's Inside

| Section | Description |
|---|---|
| **Interactive Roadmap** | Five-stage campaign timeline (Awareness → Interaction → Pre-event → Event → Post-event) with hover/focus-driven stage cards |
| **Maker Stories** | The content engine — how one maker interview multiplies into Reels, carousels, articles, quote cards, and more |
| **Content Architecture** | Ten named editorial series (Kerala Already Makes, The Thing I Made, Build With Me, etc.) with formats, phases, and publishing roles |
| **Editorial Calendar** | Phase-by-phase content cadence from mid-September through February |
| **Operating Playbook** | Five-step maker onboarding pipeline — intake → interview → capture → package → amplify |
| **People & Ecosystem** | Kerala/Kochi makers, communities (TinkerHub, MakerGram, Maker Village), and India-wide voices |
| **Measurement** | Six-tier metric ladder: Reach → Recognition → Interaction → Participation → Community → Continuity |
| **Research Notes** | Official Maker Faire references, MAKE style guide, and Kerala ecosystem sources |

## Tech

- **Single file** — `index.html` contains all HTML, CSS, and JS
- **No frameworks or build tools** — opens directly in any browser
- **Responsive** — works on desktop, tablet, and mobile
- **Print-ready** — `@media print` styles included
- **Fonts** — [Barlow Condensed](https://fonts.google.com/specimen/Barlow+Condensed) + [Inter](https://fonts.google.com/specimen/Inter) via Google Fonts

## Brand

Uses the official MAKE palette per the [MAKE Style Guide](https://makerfaire.com/wp-content/uploads/2021/08/MAKE_Style-Guide-web.pdf):

- **Red** `#EA002A`
- **Cyan** `#00AEEF`
- **White / Black / Neutral** foundation
